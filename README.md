# Job Tracker

Self-hosted трекер вакансий для личного использования. Приложение состоит из Fastify API, SQLite, веб-интерфейса и Chrome/Chromium-расширения для ручного сохранения вакансий.

Вакансия сохраняется только по явному действию пользователя **Save Job**. Сервер не открывает карьерные сайты, а расширение не выполняет фонового сбора данных.

## Компоненты

| Путь | Назначение |
| --- | --- |
| `server/` | Fastify API, SQLite, импорт снапшотов, парсеры, IMAP, AI-сервисы и бэкапы |
| `web/` | Интерфейс: вакансии, карточка, настройки и статистика |
| `extension/` | Manifest V3-расширение для захвата и отправки снапшотов |
| `shared/` | Общие Zod-схемы и TypeScript-типы |

Основные данные — вакансии, DOM-снапшоты, события, интервью, теги, письма и AI-анализы — хранятся в SQLite. Внешняя БД или облачное хранилище не требуются.

## Импорт вакансий

### Поддерживаемые источники

Для LinkedIn, Greenhouse, SmartRecruiters, SuccessFactors и Workday используются специализированные коллекторы и серверные парсеры. Они сохраняют ограниченный DOM-фрагмент вакансии и извлекают структурные поля: позицию, компанию, локацию, описание и доступные метаданные.

Неизвестные сайты обрабатываются Generic-коллектором.

### Generic-сайты и выделение контента

Для вакансии на неподдерживаемом сайте:

1. Выделите на странице блок с названием, компанией, локацией и описанием вакансии.
2. Откройте popup расширения и нажмите **Save Job**.
3. Generic-коллектор клонирует только выделенный DOM-фрагмент и сохраняет его как snapshot.

Если на странице нет выделения, коллектор использует первый доступный `main` или `article`. Если ни выделения, ни такого контейнера нет, импорт не выполняется. Коллектор никогда не отправляет весь `body` страницы.

Сохранённый Generic snapshot можно структурировать через AI в редакторе карточки. AI предлагает поля, а изменения применяются только после сохранения формы. Для повторяющихся источников предпочтительны детерминированные ATS-адаптеры.

### Инварианты захвата

- Расширение не кликает элементы, не скроллит страницу, не запускает observers и не изменяет DOM сайта.
- Не читаются cookies, токены, localStorage или сетевые ответы сайта.
- HTML очищается в расширении и повторно на сервере.
- При недоступном сервере snapshot сохраняется в IndexedDB расширения и может быть отправлен повторно.
- Импорт API защищён bearer-токеном из `API_TOKEN`.

## Возможности

- Таблица, канбан и архив вакансий; фильтры, сортировка и группировка по источнику, компании, тегам, географии и датам.
- Этапы процесса: сохранено, отправлено, интервью и результат; таймлайн событий и несколько назначенных интервью с временем и ссылкой на встречу.
- Ручные и AI-теги; нормализованная география как отдельный слой поверх исходной локации.
- AI Match с профилем кандидата, структурный разбор Generic snapshot, классификация писем и нормализация географии.
- IMAP-папки для интервью/screening и отказов, очередь подтверждения писем, сопоставление с вакансиями и обратимая обработка решений.
- Статистика откликов, воронка, когортная конверсия и разрезы по источникам, тегам, географии и AI Match.
- JSON/CSV-бэкапы и экспорт в Google Sheets через Apps Script webhook.

## AI

Поддерживаются Mistral, OpenAI, Google Gemini, Ollama и OpenAI-compatible API. Подключение содержит URL, модель, API-ключ, temperature, timeout, лимит output tokens, RPM и TPM.

Для Match, тегов и географии, почты и Generic-разбора можно задать разные подключения по умолчанию. Автоматические сценарии на импорте включаются отдельно. Общие RPM/TPM-ограничения применяются ко всем сценариям, использующим одно подключение.

В AI Match передаются профиль кандидата и текст вакансии. В Generic-разбор, тегирование и нормализацию географии передаётся только сохранённый текст вакансии. API-ключи доступны только серверу и не передаются расширению.

## Развёртывание

### Docker Compose

1. Скопируйте `.env.example` в `.env`.
2. Задайте секреты и адрес привязки:

   ```dotenv
   API_TOKEN=replace-with-a-long-random-token
   AI_SECRETS_KEY=replace-with-another-long-random-secret
   BIND_IP=127.0.0.1
   PORT=3000
   ```

3. Запустите контейнер:

   ```bash
   docker compose up -d --build
   ```

4. Откройте `http://<host>:<port>`.

Данные находятся в Docker volume `job-tracker-data`. Для доступа из LAN укажите конкретный IP хоста в `BIND_IP`; не публикуйте сервис напрямую в интернет.

### Portainer

При создании Git Stack задайте в **Environment variables** как минимум `API_TOKEN`, `AI_SECRETS_KEY`, `BIND_IP` и `PORT`. Если порт хоста занят, смените `PORT` и используйте новое значение в URL приложения и настройках расширения.

## Локальная разработка

Требуется Node.js 20+.

```bash
npm install
cp .env.example .env
npm run build
npm run dev
```

Для запуска без `.env`:

```bash
API_TOKEN=dev-token npm run dev
```

Проверки:

```bash
npm test
npm run build
```

## Установка расширения

1. Выполните `npm run build`.
2. Откройте `chrome://extensions` в Chrome или Chromium.
3. Включите **Developer mode** и выберите **Load unpacked**.
4. Укажите каталог `extension/`.
5. В настройках расширения укажите URL сервера и значение `API_TOKEN`.

## Интерфейс

- `/` — список вакансий, таблица, канбан и архив.
- `/jobs/:id` — карточка вакансии, редактор, события, интервью, теги, snapshot и AI-действия.
- `/settings` — IMAP, резервные копии, теги, профиль кандидата и AI-подключения.
- `/stats` — воронка, когортная аналитика, динамика и групповые срезы.

Повторный разбор использует уже сохранённый DOM-snapshot и обновляет только метаданные вакансии. Пользовательские теги, этап и назначенные интервью при этом не заменяются.

## IMAP

Настройте две папки: «Интервью и screening» и «Отказы». Синхронизация работает через IMAP в read-only режиме: не меняет флаги сообщений, не перемещает и не удаляет письма.

Письма с адреса IMAP-пользователя исключаются до сохранения и AI-классификации. Для входящих сообщений хранятся очищенный текст и технический ключ дедупликации; HTML, вложения и MIME-заголовки не сохраняются. Решения из очереди проверки можно отменить, если карточка после применения не менялась вручную.

## Резервные копии и экспорт

- **JSON**: вакансии, snapshots, события, интервью, теги, AI-анализы, история писем и профиль кандидата.
- **CSV**: плоская таблица вакансий.
- **Google Sheets webhook**: компактные листы `Jobs`, `Events`, `Tags` и `Emails` через Google Apps Script Web App.

В JSON не включаются API-ключи AI, пароль IMAP и секрет webhook. Перед восстановлением приложение показывает состав бэкапа; подтверждённое восстановление заменяет данные трекера, но не перезаписывает локальные секреты.

## Обслуживание

### Дозаполнение географии

Для существующих вакансий доступен отдельный скрипт. Он использует AI-подключение для тегов, не меняет ручную географию и по умолчанию пропускает архив.

В production-контейнере:

```sh
node server/dist/scripts/backfill-geography.js
node server/dist/scripts/backfill-geography.js --apply
node server/dist/scripts/backfill-geography.js --include-archived --apply
```

Локально, с пересборкой перед запуском:

```sh
npm run backfill:geo:build --workspace=server -- --apply
```
